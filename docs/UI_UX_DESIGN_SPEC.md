# سند مشخصات جامع طراحی رابط و تجربه کاربری (UI/UX Design Specification)
### پلتفرم هوشمند مشاوره و سرمایه‌گذاری املاک لوکس (ArkaEstate)
> **تدوین‌شده بر اساس استانداردهای بین‌المللی و موتور هوشمند `UI/UX Pro Max`**

---

## ۱. هویت بصری و سبک‌شناسی (Style & Design Language)

بر اساس خروجی موتور طراحی **UI/UX Pro Max** برای پلتفرم‌های تراز اول املاک و دارایی‌های لوکس (Real Estate & Property):

* **سبک اصلی:** **Glassmorphism + Swiss Minimalism (مینیمالیسم مدرن سوئیسی با متریال شیشه مات)**
  * استفاده از سطوح شیشه‌ای چندلایه با افکت بلور عمیق (`backdrop-blur-xl`)
  * خطوط مرزی مویی (Hairline 1px) با رنگ طلایی مات و نقره‌ای
  * استفاده از فضای منفی بزرگ (Negative Space) برای القای حس گران‌قیمت بودن
* **سبک‌های مکمل:** 
  * **Motion-Driven Micro-interactions:** انیمیشن‌های ملایم و ارگانیک (۲۵۰ تا ۳۵۰ میلی‌ثانیه) روی دکمه‌ها و اسلایدرها.
  * **3D Depth & Spatial Continuity:** عمق سه‌بعدی و سایه‌های شناور نرم چندلایه (`box-shadow: 0 20px 40px -15px rgba(0,0,0,0.07)`).

## ۳. طراحی دقیق نوبار (Floating Glass Pill Navbar)

نوبار به صورت کپسول شناور شیشه‌ای با فاصله `20px` از بالای صفحه طراحی می‌شود:

```
+---------------------------------------------------------------------------------------------------------+
|  [📞 مشاوره VIP]   [❤️ ۳]   |   تور صوتی   شبیه‌ساز ROI   ویزارد تطبیق [✦ AI]   املاک لوکس  |   [🏛️ ARKA ESTATE]  |
+---------------------------------------------------------------------------------------------------------+
```

### مشخصات فنی و اجزا:
1. **ابعاد و موقعیت:**
   * ارتفاع: `64px` | عرض: `max-w-7xl` | پدینگ افقی: `px-6`
   * لبه‌ها: `rounded-full` (کپسولی کامل)
   * استایل: `backdrop-blur-xl bg-white/80 border border-[#C5A880]/25 shadow-lg shadow-black/5`
2. **سمت راست (RTL):**
   * لوگو: مونوگرام هندسی طلایی + تایپوگرافی باوقار **«آرکا استیت | ArkaEstate»**
3. **مرکز (منوهای تعاملی):**
   * **املاک لوکس:** مرور کاتالوگ با فیلترهای چندبعدی
   * **ویزارد تطبیق ملک:** دارای برچسب کپسولی کوچک و درخشان: `✦ هوشمند`
   * **شبیه‌ساز سرمایه‌گذاری (ROI):** دسترسی سریع به ماشین‌حساب مالی
   * **تور صوتی محله‌ها:** راه‌اندازی مینی‌پلی‌لیست صوتی
4. **سمت چپ (اکشن‌ها):**
   * آیکون قلب (املاک نشان‌شده) همراه با نشان‌گر تعداد `[۳]`
   * **دکمه CTA اصلی:** کپسولی با گرادیان طلایی مات، متن *«مشاوره اختصاصی VIP»* و افکت هاور درخشان ملایم.
5. **حالت فشرده حین اسکرول (Scrolled State):**
   * با اسکرول کاربر، ارتفاع از `64px` به `56px` کاهش یافته و سایه `shadow-xl shadow-black/10` فعال می‌شود.

## ۴. طراحی هیرو سکشن (Dual-Impact Cinematic Hero)

ساختار هیرو سکشن به صورت ۴ لایه مهندسی‌شده برای حداکثر جلب توجه و ایجاد حس اعتبار طراحی شده است:

```
+---------------------------------------------------------------------------------------------------------+
|                                                                                                         |
|                           [ ✦ پلتفرم نسل جدید انتخاب و تحلیل سرمایه‌گذاری املاک ✦ ]                       |
|                                                                                                         |
|                               خانه‌ای که دقیقاً با سبک زندگی و                                           |
|                                    آینده مالی شما نفس می‌کشد                                             |
|                                                                                                         |
|               ترکیب تحلیل مهندسی، هوش محاسباتی بازگشت سرمایه و مشاوره ۳ کارشناس مستقل                   |
|                                                                                                         |
|      +-------------------------------------------------------------------------------------------+      |
|      |                                                                                           |      |
|      |    [🎯 تطابق با سبک زندگی: ۹۶٪]                                                           |      |
|      |                                                                                           |      |
|      |                               تصویر/ویدیوی سینمایی پنت‌هاوس لوکس                          |      |
|      |                                                                                           |      |
|      |                                                [📈 سود تخمینی ۵ ساله: ۳۲٪ سالانه]         |      |
|      |                                                                                           |      |
|      +-------------------------------------------------------------------------------------------+      |
|                                                                                                         |
|                 +-------------------------------------------------------------------------+             |
|                 | [سکونت آرام] [سرمایه‌گذاری] | محله: نیاوران | بودجه: اسلایدر | [شروع ویزارد] |             |
|                 +-------------------------------------------------------------------------+             |
|                                                                                                         |
|          [ ۴۵۰+ میلیارد تومان ارزیابی ]    [ ۹۴٪ دقت تطابق ]    [ ۳ کارشناس تحلیلگر ]    [ ۱۰۰٪ شفافیت ] |
|                                                                                                         |
+---------------------------------------------------------------------------------------------------------+
```

### تفکیک ۴ لایه هیرو:

1. **لایه اول: تیتر ادیتوریال و برچسب ارزش (Editorial Headline):**
   * برچسب بالایی: کپسولی باریک با پس‌زمینه طلایی شفاف: `✦ نسل جدید پلتفرم انتخاب و سرمایه‌گذاری املاک لوکس ✦`
   * تیتر اصلی: تایپوگرافی سنگین، خط اول مشکی عمیق و خط دوم با گرادیان طلایی شامپاینی.
   * زیرتیتر: حداکثر ۲ سطر روان با رنگ خاکستری تیره (`#4B5563`).

2. **لایه دوم: قاب سینمایی با ۳ کارت شیشه‌ای معلق (Floating Smart Cards):**
   * یک فریم عریض با حاشیه گرد `rounded-3xl` با تصویر یک پنت‌هاوس مدرن.
   * **کارت معلق ۱ (بالا-راست):** نشان انطباق هوشمند `🎯 تطابق با نیاز شما: ۹۶٪` (با آیکون سکونت آرام).
   * **کارت معلق ۲ (پایین-چپ):** سنجه رشد مالی `📈 سود تخمینی سالانه: ۲۸٪` (همراه با مینی‌نمودار سبز صعودی).
   * **کارت معلق ۳ (پایین-راست):** تصویر کوچک ۳ کارشناس تحلیلی با متن: *«تاییدشده توسط مهندس سازه و حقوقی»*.

3. **لایه سوم: کنسول جستجوی هوشمند شناور (The Hero Search Console):**
   * قرارگیری به صورت نیمه‌شناور روی لبه پایین تصویر هیرو.
   * تب‌های تعویض هدف: `سکونت خانوادگی` | `سرمایه‌گذاری پربازده` | `پنت‌هاوس و برج‌باغ`
   * فیلد انتخاب منطقه و محله‌های لوکس
   * اسلایدر تعاملی بازه بودجه با شمارنده لحظه‌ای میلیارد تومان
   * دکمه اقدام بزرگ طلایی: **«شروع ویزارد تطبیق هوشمند ملک ✦»**

4. **لایه چهارم: نوار شاخص‌های اعتمادساز (Social Proof Trust Bar):**
   * ۴ ستون آماری مینیمال با اعداد بولد و عناوین زیر آن‌ها:
     * **۴۵۰+ میلیارد تومان** ارزش املاک کارشناسی‌شده
     * **۹۴٪** نرخ رضایت و تطابق سلیقه خریداران
     * **۳ کارشناس** ارزیابی مستقل برای هر ملک
     * **۱۰۰٪** اصالت اسناد و تضمین قرارداد

## ۵. استانداردهای UX و دسترس‌پذیری بر اساس قوانین UI/UX Pro Max

* **ابعاد لمسی (Touch Targets):** تمامی دکمه‌ها و فیلدها دارای ارتفاع حداقل `44px` تا `52px` هستند.
* **کنتراست متون (WCAG 2.1):** حفظ نسبت کنتراست بالای `4.5:1` برای متون روی پس‌زمینه‌های شیشه‌ای و روشن.
* **انیمیشن و حرکت:** استفاده از ترنزیشن‌های استاندارد `cubic-bezier(0.16, 1, 0.3, 1)` برای باز شدن نرم مودال‌ها و منوها.
